# 刘老｜初中语文阅读教学设计

用余映潮《余映潮谈阅读教学设计》的教材处理方法，按本校七上、七下、八上教案形成的阅读路径备课。先从课文字句及结构找出学生值得花时间解决的疑问，再让学生用证据逐步作答。四项目标、两道确认、固定记录本与配时属于本校交付口径。书中的课例可以有几个板块层面的主问题，本校每课时定一个统摄问题，其余放入问题链。保留这个区分。

## 先判断用户要什么

- **完整教案**。走两道确认，之后默认交付 Word。多课时分课时组织，每课时各有一个主问题，统摄于同一个整篇选点。每一轮只确认当前课时的一个对象，冻结通过内容再进入下一轮。
- **只要主问题、问题链、活动、板书或导学单**。只交付这一项。做问题链需要已有主问题，用户已明说的主问题可以直接使用；缺少时先提出主问题。审已有教案时从最影响学生学习的两三处查起，给出原处、问题与改法。
- **核对教材身份**。以用户指定版本的课文、单元导语和课后习题为准。遇到实际教材与资料归档不符，按教材核对；遇到同名、改版、省略号、分段差异，核实用的是哪一稿。用户仅给课名且无法取得可信全文时，索取教材页、原文或可用片段，再做依赖全文的判断。备课人、班级等元信息不和确认混问；进入制稿后单独补问，缺信息时填“待定”。日期使用用户给定的授课日，文件名日期使用制稿日期或用户指定日期。

## 两道确认

1. **素读、校准、确认主问题。** 写下暂定选点和原文依据，然后按下一节检索校准。内部可试 6–10 个问法，用“可讨论、统摄面、必须取证、简洁”四项各 0–2 分筛选，优先总分 ≥6 且有真实分歧的一个。尽量约 25 字、一个问号，保留课文需要的具体词。试写两种合理的初答，看至少哪个字句或段落关系能改变判断。给用户一个主问题和至多一句选点依据。用当前宿主已有的确认弹窗索取“通过／修改”；弹窗不可用就用当前对话只问这一件，收到明确回复后再推进。
2. **确认问题链。** 首次明确通过后，才给 2–4 个由浅入深的子问题。每个后标“→活动X”，说明它为下一问新增了哪份文本证据或判断。只确认这条链。修改链时保留已确认主问题；主问题一旦更换，旧链失效，重新走两道确认。等待期间可以查证和核对模板。两道均获明确确认后才写教学过程和详细正文。后续若发现原文依据有误，指出受影响的确认项，请用户只重审该项。
3. **展开和交付。** 按课型走教读或自读；把用户已经确认的问句原样放入教案，并在结尾回扣。用户要求局部修改时，只重写被修改的步骤及直接受影响的下游内容。

## 备前检索

素读记录至少留三样：一句能统连全文的文字或结构现象、两处可读证据、一个学生可能的初答。然后查本册单元要求、课后练习和对应课标，再查常见读错处、可核实的考法。尽量使用教育部门、出版社和正式试题原页。余著中出现的课程标准有其出版年代，当前教案按当前教材与课标校准。

每课以 3–5 篇可核文献为检索目标，主动找至少 1 篇有依据地质疑常见解读的文章。维普详情页作主要入口，期刊官网核篇名、作者、年份、刊期／页码；带 DOI 再用 Crossref，百度学术只找线索。知网直连不作为工作入口。A 级为原发期刊、公开正文且论证能核查，B 级为可核题录且明确读到相关论点，C 级为转载、匿名、纯感想或仅见标题。再看论证过程及教材版本；剔除靠大词断言、例子与结论无关的观点。检索不足如实登记，结论回到正文；检索不到反例时可用两种文本解释做课堂验证，勿编造对立论文。

缓存到本次项目的 `备课文献缓存/课文.md`，写日期、完整题录、原页链接、可核论点、使用取舍及缺项“待核”。文献只校准重点、目标和误读，在教案正文自然转化为教学判断，保留本地出处。直接引语及外部统计确需进入学生材料时标明原始来源；普通教案正文省略论文题录。用户单独要求“查论文”时，使用这套检索和甄别流程，交付可点击的题录与取舍，不写教案、不做查重或 AI 检测。禁用无名的“研究表明”。假如外部材料和课文字义相冲突，把两者给学生比较或舍弃该材料。

## 能力卡

| 要解决的困难 | 操作与验收 |
| --- | --- |
| 1. 选点与整体阅读 | 先让学生做一次面向全文的提取、复述、排序或命名。再选择关键字、段、结构或语体重读，让学生回扣整体。如长篇叙事用标题或时间线扫全篇，再挑能改变解释的两处。输出要带段或短句定位。见余著 §17–23、§30–31。 |
| 2. 设计主问题 | 试换题、删段、调序、对照初读与复读、从反常细节发问。问题要能支撑静读与书写，再选一个。若“作者写了什么”一轮抢答即结束，它只适合作为子问。借鉴《秋天的怀念》的题意追问、《猫》的证据再读，但根据本篇改题。见余著 §26–27。 |
| 3. 排问题链 | 先做一件留痕的小事获得证据，再用另一段或反例比较，最后推到主问题的解释。删除一问若不影响后问，多半是碎问；后问若根本不使用前问产物，则需重排。允许前后比较、并例归纳、认知修正，择一使用。 |
| 4. 排板块 | 以学生的整段实践组织课时。教读 40 分钟可起于 4＋8＋22＋6，依文本调整。计入导入、读写、展示、转场与收束的实际耗时，不把同一分钟计给两个环节。教师说明、点拨与讲析合计按下文总账。见余著 §24–25。 |
| 5. 写学生活动 | 指定原文位置、动笔方式、用时、交什么、如何判断完成。先独立圈画或写，再交流；至少保留一次 3–8 分钟真正独立动笔。教读一般让工作表、短批注、对照结果、短写话四类产物出现至少三类，可由同一活动连续生成，保留对主问题有用的产物。浅文可提高任务难度，难文先补最小字词或结构支架。 |
| 6. 给支架 | 示范一格／一句即可让学生沿同一路径独做下一处。初答卡住就给证据范围；找到字但解释空泛就给比较对象；已有充分证据就撤支架。避免公布整张答案表。板书或教师示范要在学生动笔之后回收结果。 |
| 7. 做语言训练 | 教读先回到关键字的语境，让学生标重音、停连、语气并指出理由；或比较替换词、词序、限定词，有证据再归纳写法。写作只仿本课所学的一种结构、句式或证据组织方法，给样例与一个可检查要求。见余著 §3–7、§28–29。 |
| 8. 用课文带写 | 可写一条短评、段落改写、人物补白、仿句、现场说明。让产物成为下一问的输入或迁移证据。小说补白不能改情节约束，说明文改写须保留对象、单位和限定，新闻写作分清事实与判断。 |
| 9. 定四条目标 | 按积累、理解、品味、价值各一条。动词可以是圈出、比较、解释、改写、拿证据说明。后三条分别承担主问题答案的一部分，并逐条能指到活动和学生产物。“价值”写学生如何根据证据辨析人物选择或表达判断。 |
| 10. 写教师话语与预设 | 给能直接开口的短指令，含对象和边界。“看第三段‘轻轻’那个词，换成‘使劲’再读一句”比“品味语言的丰富内涵”可操作。重点活动预设有根据、偏读和沉默／不完整几种，分别给下一句提示。教材事实用陈述句，班情推断标〔预判〕。 |
| 11. 读法与双卷 | 自读课只选一种可迁移读法，用一个工具支撑，学生至少有一次自选。导学单的教师卷在相同题面后增加答案范围、判据和应对。下节给新文本时，学生仍能照清单执行。 |
| 12. 审稿与板书 | 沿“主问题→子问→活动→产物→四项目标”逐项反查。板书 ≤3 行，用一字或一个词立骨，能凭结构复原主问题的答案。教学中明确写上黑板的条目按出现顺序对应全集；无关教学用语不算板书。反思只写待验证的用时、支架、最弱活动三问。 |
| 13. 组装交稿 | 比对已确认问句、课型、课时、元信息和本校表格。生成 Word 后检查真实末页、单元格换行、标题、板书、双卷和文件名。运行方式见本文末节。 |

### 把握不同文体的落点

- **散文与小说**。先用事件链、前后用词或视角关系看全篇，再让学生拿短句修正第一反应。《猫》把叙述者自信的推断放回事件证据；《济南的冬天》把重音与停连选择和画面、情感连起来；《背影》类回忆文本可比较事情发生时与回忆时的眼光；《藤野先生》用“怀念恩师能否解释全文”将非交往段落纳入证据，避免两条线各说各话。
- **诗歌及文言**。落实必要诵读和疏通，选一处值得反复对照的字、句式、意象或动作。用对照诵读或受约束的译写，让学生说出差异。《短文两篇》可抓“不陋”的理由与遣词，《三峡》可读顺序并用一段景物验证结构。遇到课内联读，定一个共同尺度，各篇承担不同的轻重，不把两套完整流程串起来。
- **说明文**。把对象特点交给学生验证。先复原说明次序，再检查材料把特点说实了没有。可以用实物标注、工序图、换序和删限定语。《活板》从“活”追到制、排、印、拆，《中国石拱桥》检验用例怎样撑住特点，《苏州园林》把局部安排放回总特征。不能靠背术语替代说清关系。
- **新闻、传记和议论**。如八上《特写通讯评论整合教学设计》，新闻先按体式识别信息与来源，再比句段如何呈现事实，防止把题材相同误判成体式相同。传记用人与事件的选择、正侧材料互证。议论用半成品图让学生补出观点、理由及论证关系，再找一项具体情境检验。整组新闻教案可借用体裁比较，用户要求的整单元项目不套单课流程。
- **自读、长文**。标题与旁批可以先当导航，给学生一个可复用的略读或批注动作，教师只处理确实卡住的部分。原本导学单漏掉旁批示例时，把示例恢复在学生卷。长文先定位、精读一点再回全篇。短文可加证据层次，别把所有字都问遍。

## 教读课怎么写到能上课

教学过程按“课时题→主问题→子问题及活动编号→导入→任务一及步骤→过渡→任务二及活动→总结”，必要时增减主任务数，名称用“四字短语＋动宾”的语感，动词要和实际任务一致。默认每课时过程正文至少 3000 字，含学生动作、写作支架、预设分支与验收，按课时分别计算。导入 80–150 字，总结 150–250 字，收束复述已确认主问题原话并让学生用证据回答。

承载主问题的活动写全七项：师（原话）、生（位置／动作／时间／动笔）、预设（2–3 类回答和回应）、师讲（必要要点带例）、收口（可核答案或保留分歧）、板书（用「」标字）、过渡（原话）。短的过渡或检查允许写少项，具体说明它怎样把下一步交给学生。一处辅助问题可留待续探，主问题仍要有证据收束。避免为了齐七项重复讲解。课堂口播按整课时汇总，含导入、师讲、指令、过渡、总结和会实际说出的应对，互斥分支按最长可行路径检查，并保留口播总账。常规课教师 6–8 分钟且 ≤1600 字，文言难文按实际需要最多 12 分钟且 ≤2400 字；用试读校正，不以加速念稿代替取舍。

## 自读课怎么让学生自己读

同样先确认一个主问题或主任务及其问题链。40 分钟五段：3 分钟交代读法；7 分钟独立用工具；17 分钟完成自选任务；9 分钟全班用巡视时选出的样本说明过程；4 分钟归纳方法清单。全班展示不安排小组互看。写时间、动作、工具与产物，教师话语总计 ≤600 字，保留必要的两处点拨。选一种读法（如用旁批自问、略读定位、批注、补半成品导图），给一件工具，最后收 3–5 步能在下一篇复用的清单。

另出 Word 导学单，学生卷在前、教师卷在后。两卷用同一套“读法提示／工具／任务／自评”，同题号、同题面、同示例、同工具。学生卷留可写位置，教师卷只在对应位置加答案、常见误读和评价。参考《再塑生命的人》的读法迁移与《有为有不为》的双卷构造。《“蛟龙”探海》和《太空一日》的薄弱处提示：题面留着却删掉示范，学生仍然无从起步。

## 文风两道检查

第一遍找八类问题：主体消失、句尾空评、强凑三点、板块名对仗、学生答成标准作文、教师播音腔、步步盖章、空泛评价。逐句看谁对哪处文本做了什么、用多久、留下什么。学生可能先说半句或指错段，教师可暂停、缩小范围、请学生再读；句子长短随实际内容。至少一处辅助话题允许上课保留开放，学生的不同解释以证据裁决。

交稿前再查对句、编号堆叠、表演性的精确数字（全篇约六处以内，真实活动分钟与总账不计）、口播和〔预判〕。将“赋能、抓手、闭环、彰显、提质增效、层层递进、潜移默化、理解得到加深、感受到美”等空话改成动作和证据。拆掉“通过……从而……”“以……为抓手”“不仅……更是……”式空转。保留教材术语与有功能的真实清单。最后读一遍所有师话、用原文校对数字和引语、查板书顺序；不要把设想写成真实课堂观察。

## 术语与决策速查

| 术语 | 临场决策 |
| --- | --- |
| 素读／选点 | 素读保留首次从词句得出的判断；选点从内容、部位、角度三项定重点，并能回到全篇。 |
| 整体阅读／整体反复 | 第一遍建立图景、时序或文意；再带不同任务回全篇，各次新增一种证据或能力。 |
| 主问题／问题链 | 主问题承担有时长且能落笔的整块实践；链中的每问改变证据、解释或迁移条件。 |
| 板块／支架 | 板块是一段时间内真正做的语文实践；支架是一格示范、可用工具或有限提示，用完能撤。 |
| 文意把握／品析 | 先说文章写了什么和如何组织，再拿词句解释表达。会写“用比喻”仍要说明它使哪个形象如何出现。 |
| 语言学用／以写带读 | 读时发现表达规律，用关联的新材料练一回。需要迫使学生重读原文时，可先布置写作任务形成阅读目的。 |
| 长文短教／短文细教 | 长文精选而保全局，短文反复读且增训练层级；二者都依文取舍。 |
| 教读／自读 | 教读示范如何取证并把练习交给学生；自读练已有方法，发工具、留选择、收步骤。 |
| 过程评价／反思 | 用真实产物检测能否回答主问题；教学反思在备课时写要验证的三问，上课后的判断由教师补。 |

## 全书概览与来源锚点

《余映潮谈阅读教学设计》现有工作本含序和 35 节。序把发现落在材料、表达规律、训练需求和可操作的做法；§1–8 说明教材的用法、读写训练、活动与积累；§9–16 讨论活动创意如何实、新、精、美、活、丰、趣、雅；§17–23 讲先研读后取舍、选点回到整体、文意与结构；§24–27 将主问题变成有时长的课堂实践；§28–35 讲活用、巧用、长文短教、短文细教、一课多篇、浅文上深和难文上明白。用章号定位本书方法，把样本视为具体课例。两个近同稿不能算两份独立经验；课例只能说明有过这种设计，不能据此声称有课堂效果。

本校样本的稳定做法是选点先落文本、题意或前后关系生发问题、示范后独做、最后以产物作答。《雨的四季》保留换题追问，同时补上与写作目标对得上的当堂产物；《谁是最可爱的人》两种版式看作一个设计家族，并逐栏查异篇措辞；《太空一日》要对齐教案示例与学生卷。八上新闻、说明文和文言样本用于校准文体判断，不把共享备课人作品统称用户本人作品。用户明确确认的设计，比组内格式频率更能决定个人风格。

## 按本校原模板生成 Word

本 Skill 的教学规则、案例、术语、速查都在本文。随附的 Word 模板和脚本负责填表。使用模板的 14 行 × 6 列及原合并关系，小四仿宋。原样保留顶部校名、“总____课时”和备注表头。若给了总课时序号，填入右上角。第 12 行右侧原模板并无独立备注内容格，简短备注、作业或量表按需写在教学过程末，保留原合并；正文没有单列作业或量表。文件命名为“课题-备课人-日期.docx”，导学单同基名加“-导学单”。多个课时同稿时每课时单列过程、写清各自的起止时间。

在独立目录写 UTF-8 的 JSON，字段全部用字符串，分段使用 JSON 的换行，`total_period` 为可省略的正整数。日期缺省填“待定”。`goals` 每行一条、共四行；`board` 不超过三行；`process` 即完整过程及可选备注。输入字段名如下。

```text
teacher class date type title standards text learners goals focus difficulty
methods process board reflection total_period
```

用有 lxml 的 Python 运行本目录 `scripts/render_lesson.py lesson 成稿数据.json 输出教案.docx`。自读课另写一个 JSON，结构为 `{"title":"课题","student":{"读法提示":"…","工具":"…","任务":"…","自评":"…"},"teacher_notes":{"读法提示":"…","工具":"…","任务":"…","自评":"…"}}`，以 `guide` 子命令生成（另需 python-docx）。两卷共用同一份题面，教师批注作为追加文本。导学单留出填答区域，必要时用可打印的表格或半成品图。脚本不覆盖目标文件。可用 Word 或宿主的文档工具时，同样从模板副本填格并回读。出稿后逐页预览；中文字体缺失、分页或扫描限制使预览不可核时，如实汇报。只有用户明确只要文本时才默认按表格字段返回文本。
