# 刘老 · 初中语文教学设计

一个给 AI 用的初中语文教案 Skill。把余映潮的阅读教学设计方法，压到一套固定的「教师备课记录本」体例上，让模型一次产出能直接打印、直接上交的教案表格。

## 它解决什么问题

通用模型写教案有两个通病：要么写成教学论八股（「引导学生体会作者的思想感情」），要么格式不对——学校要交的是那张 14 行 × 6 列的表，不是一个漂亮的文档。

这个 Skill 干的事很具体：把模糊的判断变成可执行的步骤，把格式钉死成表格。

- 先回答「这篇课文该教什么」，逼你在 40 分钟里砍掉讲不完的内容
- 主问题只留一个，其余问题降级成子问题链
- 板块按分钟落位，每一块必须挂一个学生活动
- 最后套进表格：课标分析、教材分析、学情、目标、重难点、教学过程各归各位

## 13 项能力

| 你遇到的问题 | 对应小节 |
|---|---|
| 这篇课文该教什么；内容太多讲不完；长文短教 | 1 选点与教材处理 |
| 帮我出个主问题；问题太多怎么收敛 | 2 主问题设计 |
| 问题链怎么排；子问题怎么递进；怎么追问 | 3 问题链设计 |
| 这节课怎么分段；每段几分钟；板块式怎么用 | 4 板块与课时结构 |
| 活动怎么设计；学生不动笔；讨论冷场 | 5 课中活动设计 |
| 怎么让学生用上课文的写法；句式段式怎么练 | 6 语言学用训练 |
| 课中写什么；读写结合怎么做 | 7 以写带读与微型写作 |
| 目标怎么写；三维还是素养；怎么算达成 | 8 目标设定与达成 |
| 这份教案有什么问题；怎么自查 | 9 设计审稿自查 |
| 设计《XX》；写一份完整教案；按记录本格式出稿 | 10 整篇教学设计组装（产出 .docx 表格） |
| 导学单怎么出；学生卷教师卷怎么分 | 11 导学单双卷 |
| 过渡语、评价语、指令语怎么说 | 12 教师课堂语言 |
| 教案写得过细；口播写太满；要简案 | 13 详略分配（写会忘的，不写会说的） |

适用范围：统编版七上、七下的教读课、自读课、文言文、古诗，单篇课时。

不适用：非语文学科、试卷命题、作文批改、班级管理，以及大单元和学习任务群的整体方案。

## 用法

不用记命令，按自然语言说就行：

```
设计《狼》这一课，按备课记录本格式出稿
帮我出个主问题
问题链怎么排
这份教案有什么问题
教案太细了，压一压，要简案
```

出整份教案时它走「三步走」：先确认主问题，再确认问题链，最后写正文。每一步只问一件事，不会一口气吐三千字让你无从修改。

## 关于这份文件

- 体例来自某校现行的「教师备课记录本」，仓库版本已做脱敏：学校名替换为「某某学校」，他人姓名替换为「本校教师」
- 方法论出自余映潮《余映潮谈阅读教学设计》（中国人民大学出版社，2019）。这份 Skill 是方法的操作化改写，不是原书摘录，需要完整论述请读原著
- 单文件全量版：所有判断、步骤、案例、术语都在 SKILL.md 内，运行时不需要读任何外部文件
