# 刘老 · 初中语文教学设计

## 阅读教学新版

新版结合七上、七下、八上教案与余映潮的阅读教学方法，支持分两步确认备课思路，并按学校模板生成 Word 教案。自读课配学生卷和教师卷。

[下载安装包](downloads/liu-lao-reading.zip) · [新版 Skill](liu-lao-reading/SKILL.md) · [使用与验收](liu-lao-reading/README.md)

一个给 AI 用的初中语文教案 Skill。把余映潮的阅读教学设计方法，压到一套固定的「教师备课记录本」体例上，让模型一次产出能直接打印、直接上交的教案表格。

## 它解决什么问题

通用模型写教案有两个通病：要么写成教学论八股（「引导学生体会作者的思想感情」），要么格式不对——学校要交的是那张 14 行 × 6 列的表，不是一个漂亮的文档。

这个 Skill 干的事很具体：把模糊的判断变成可执行的步骤，把格式钉死成表格。

## 顺序：先素读，再检索

这是这份 Skill 最不肯让步的一条。

**素读定选点**：不看任何参考资料通读课文，标出三处疑惑，写下一句「只有这篇能用」的话，落成暂定选点。

然后才做**备前检索**：先查本单元导语与单元要求、这篇课文公认的教学难点与常见误读、中考常见考法；再找 3—5 篇文献，只取观点。

顺序不能反。理由很实在——先读别人的解读，你的选点就变成别人的选点了，这正是余映潮反对的「不读原文先看教参」。

检索只做三件事：**确认**（我的判断站得住）、**推翻**（原来看漏了）、**补充**（多一个角度）。**不许直接换掉你的选点**；要换，必须写一句「原判断错在哪」。

文献管「教什么」（重点、目标、学情），不管「怎么教」（流程、问题链、活动）。取用前三道筛定级，只取 A、B 级。

## 写作流程

出整份教案走「三步走」，每一步只确认一件事：

1. **主问题** —— 只出主问题，等确认
2. **问题链** —— 只出问题链，等确认
3. **正文** —— 再写

## 12 条常驻底线（节选）

无论做哪一节都适用。原文有 12 条，摘 4 条看调性：

- **主问题唯一**：一节课只解决一个认知冲突，其余问题降为子问题或改成活动
- **当堂动笔**：必须有 3—8 分钟的独立实践活动并落笔；全课无一次动笔的设计直接推翻
- **教师讲时**：默认 6—8 分钟，文言与难文 8—12 分钟；必须排在学生活动之后、只讲学生讲不出的、讲完给二次动作
- **四段配时**：情境导入 3—5′ → 整体感知 8—12′ → 精读品析 20—25′ → 迁移收束 5—8′，合计 40′

还有一条硬账：**口播＝所有「师：」句＋所有「师讲」要点**，按 200 字／分钟折算，必须 ≤ 你安排的讲授分钟数。写超了就是排不下，不是讲快一点的问题。

## 13 项能力

| 你遇到的问题 | 对应小节 |
|---|---|
| 这篇课文该教什么；内容太多讲不完；长文短教 | 1 选点与教材处理 |
| 帮我出个主问题；问题太多怎么收敛 | 2 主问题设计 |
| 问题链怎么排；子问题怎么递进；怎么追问 | 3 问题链设计 |
| 这节课怎么分段；每段几分钟；板块式怎么用 | 4 板块与课时结构 |
| 活动怎么设计；学生不动笔；讨论冷场 | 5 课中活动设计 |
| 怎么让学生用上课文的写法；句式段式怎么练 | 6 语言学用训练 |
| 课中写什么；读写结合怎么做 | 7 以写带读与微型写作 |
| 目标怎么写；三维还是素养；怎么算达成 | 8 目标设定与达成 |
| 这份教案有什么问题；怎么自查 | 9 设计审稿自查 |
| 设计《XX》；写一份完整教案；按记录本格式出稿 | 10 整篇教学设计组装（产出 .docx 表格） |
| 导学单怎么出；学生卷教师卷怎么分 | 11 导学单双卷 |
| 过渡语、评价语、指令语怎么说 | 12 教师课堂语言 |
| 这篇自读课怎么上；带星号那篇；自读课导学单 | 13 自读课与导学单 |

第 13 节值得单说：自读课**不是**教读课少讲一点，是换一种课。一节课只做三件事——教一种读法、给一件工具、收一份方法清单。教案不写逐字稿，教师话语 ≤ 600 字，配套产出导学单双卷。

适用范围：统编版七上、七下的教读课、自读课、文言文、古诗，单篇课时。

不适用：非语文学科、试卷命题、作文批改、班级管理，以及大单元和学习任务群的整体方案。

## 用法

不用记命令，按自然语言说：

```
设计《狼》这一课，按备课记录本格式出稿
帮我出个主问题
问题链怎么排
这份教案有什么问题
这篇是自读课，怎么上
出一份导学单
```

出整份教案时它会先问主问题、再问问题链，最后才写正文。每一步只问一件事，不会一口气吐三千字让你无从修改。
